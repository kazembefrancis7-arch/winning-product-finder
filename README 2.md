# Winning Product Finder — iPhone/PWA

This version is packaged as a Progressive Web App.

## Install on iPhone
1. Host this folder on an HTTPS web host.
2. Open the site in Safari on your iPhone.
3. Tap Share.
4. Tap **Add to Home Screen**.
5. Tap **Add**.

It will launch in standalone app mode with its own Home Screen icon.

## Current limitation
The product intelligence in this prototype uses demonstration data. A production version should connect the scoring engine to live market signals, supplier costs, local competition and AI analysis.
